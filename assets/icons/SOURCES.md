# Icon sources

Technology icon strips are from [Skill Icons](https://github.com/tandpfun/skill-icons), distributed under the included MIT license. Downloaded from skillicons.dev with the dark theme; hosted locally so the profile does not depend on the service at render time.

- `languages.svg`: Python, Java, JavaScript
- `applications.svg`: FastAPI, React, Node.js, Express, Spring
- `ai.svg`: OpenCV, scikit-learn
- `data.svg`: PostgreSQL, Redis
- `cloud.svg`: Docker, Kubernetes, OpenShift

Brand marks identify the technologies and remain the property of their respective owners.
